One line roasting an alarm clock for ringing at 6 AM on a Saturday morning — a make.fun bounty entry by [@laithzz21](https://github.com/laithzz21).

## The roast

> Dear alarm clock: it's 6 AM on a Saturday. The only thing you should be waking is your own sense of shame. Snooze, traitor.

## Run it

```bash
python3 main.py
```

It prints the roast to stdout and writes it to `/tmp/sweep27-u-carbon-forge-snooze-button-roast-14cbafc6/entry.txt`.
